## Структура

```
index.html        головна (всі секції)
privacy.html      політика (чернетка — практика має замінити своєю)
404.html
assets/styles.css дизайн-система
assets/app.js     уся логіка: години, лічильник, слайдер, тест, форма, меню
assets/favicon.svg
api/lead.js       Vercel-функція: приймає заявку і пересилає її
og.jpg            картинка для соцмереж
vercel.json       заголовки безпеки, кеш, чисті URL
robots.txt        індексація вимкнена (поки це концепт)
```

Збірки немає — це чистий HTML/CSS/JS. Шрифти (Archivo, Inter, JetBrains Mono) тягнуться з Google Fonts.

## Деплой на Vercel

1. Завантаж вміст цієї папки в новий репозиторій GitHub (щоб `index.html` лежав у корені).
2. vercel.com → **Add New → Project** → обери репозиторій → **Deploy**. Framework: *Other*, нічого не міняй.
3. Заявки: **Settings → Environment Variables**, додай хоча б один канал і зроби **Redeploy**:

| Канал | Змінні |
|---|---|
| Telegram (найпростіше) | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Email через Resend | `RESEND_API_KEY`, `LEAD_TO_EMAIL` (можна кілька через кому), опційно `LEAD_FROM_EMAIL` |
| Будь-який вебхук (Make, Zapier, n8n, Google Sheets) | `LEAD_WEBHOOK_URL` |

Без жодного каналу функція відповідає 503: у демо сайт показує «заявку не доставлено (демо)»,
а в бойовому режимі просить подзвонити.

## Режим «концепт» → бойовий сайт

Зараз увімкнено `demo: true` у `assets/app.js`: зверху плашка «Concept redesign — not the official
website», у футері — та сама примітка, індексація вимкнена.

Коли практика погодиться:

1. `assets/app.js` → `demo: false`.
2. `index.html` → прибрати `<meta name="robots" content="noindex, nofollow" />`.
3. `robots.txt` → `Allow: /`, додати `sitemap.xml` з їхнім доменом.
4. Отримувач заявок — їхня пошта/Telegram (змінні в Vercel).
5. `privacy.html` замінити їхньою політикою (HIPAA-нюанси вирішує практика).

## Що звірити з практикою перед запуском

- **Години**: на їхньому сайті Fri 8–4:30, Sat 8–3; у Google — Fri 8–5, Sat 8–2. На сайті взято їхні власні.
  Міняються в `SITE.hours` (`assets/app.js`), у таблиці годин, у футері, у топ-барі та в JSON-LD (`index.html`).
- Чи пропонують досі **закис азоту** (згадано у відгуках) і **ортодонтію**.
- Цитати з відгуків — короткі уривки з публічних відгуків Google/Birdeye без імен;
  краще замінити на відгуки, на які практика дасть згоду, або підключити віджет Google.
- **Фото**: зараз скрізь SVG-ілюстрації. Справжні фото лікарів (замість монограм EP/SD), команди
  й кейсів «до/після» підніміть сайт ще на рівень — місця під них уже є.
- Номер `346-586-1002` зі старого сайту — з'ясувати, що це (call tracking?).
