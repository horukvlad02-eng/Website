# Acadian Family Dental — концепт редизайну (мультисайт, EN + ES)

Приватний концепт-редизайн сайту стоматології **Acadian Family Dental**
(Х'юстон, Техас): 18 сторінок × 2 мови, генератор статики, реальні фото команди,
перевірені факти, чесні заявки.

> **Це не офіційний сайт клініки.** Сайт не індексується (`noindex`, `robots: Disallow`),
> плашка про концепт висить на кожній сторінці, а заявки з форми приходять розробнику,
> а не в клініку.
>
> **Живий демо-сайт:** https://acadian-family-dental.vercel.app · код — гілка `acadian-family-dental`
> у репозиторії `horukvlad02-eng/Website`.

## Як зібрати

```sh
python3 build/build.py        # перегенерувати всі 36 сторінок + sitemap + i18n
```

Потрібен лише Python 3.9+. Збірка не потрібна для деплою: Vercel віддає статику як є.

## Локальний запуск

```sh
python3 -m http.server 8080   # http://localhost:8080
```

Форма локально не надішле заявку (є `/api/lead` лише на Vercel) — у демо-режимі вона все одно
показує підтвердження з поміткою, що запит нікуди не дійшов.

## Деплой на Vercel

1. Завантажте вміст цієї папки в новий репозиторій GitHub (щоб `index.html` лежав у корені).
2. vercel.com → **Add New → Project** → обери репозиторій → **Deploy**.
   Framework: *Other*, нічого не міняй — `vercel.json` уже готовий.
3. Заявки: **Settings → Environment Variables** і **Redeploy**.

| Канал | Змінні |
|---|---|
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Email через Resend | `RESEND_API_KEY`, `LEAD_TO_EMAIL`, опційно `LEAD_FROM_EMAIL` |
| Будь-який вебхук (Make, Zapier, n8n, Google Sheets) | `LEAD_WEBHOOK_URL` |

Без жодного каналу функція відповідає 503, а сайт показує «заявку не доставлено» і просить подзвонити.

## Режим концепту → бойовий сайт

Зараз увімкнено `demo: true` у `assets/config.js`:
- плашка «Concept redesign — not the official website» на кожній сторінці;
- `noindex, nofollow` + `X-Robots-Tag` у `vercel.json` + `robots.txt` із `Disallow: /`;
- заявки йдуть туди, куди вкажуть змінні середовища у Vercel (Telegram / Resend / вебхук) — тобто розробнику.

Коли практика погодиться:

1. `build/build.py` → `"demo": False` у блоці `config` (або одразу в `assets/config.js`), у Vercel — змінні з пошти/Telegram клініки.
2. Прибрати `<meta name="robots" content="noindex, nofollow" />` у `build/render.py` (`head()`) і перезібрати.
3. Видалити блок `X-Robots-Tag` із `vercel.json`, у `robots.txt` → `Allow: /` + `Sitemap:`.
4. Домен для `sitemap.xml`, canonical, hreflang і OG-картинки — `SITE["site_url"]` у `build/data.py`, потім `python3 build/build.py`.
5. Замінити тексти `privacy/` на політику клініки (`LEGAL_EXTRA` у `build/pages.py`; HIPAA-нюанси вирішує клініка).

## Що звірити з практикою перед запуском

- **Години.** На їхньому сайті: Пт 8–16:30, Сб 8–15. У старих знімках Google: Пт до 17:00, Сб до 14:00.
- **Чи беруть нових пацієнтів на ортодонтію** (сторінка з брекетами є, в меню — ні).
- **Номер 346-586-1002** зі старого сайту — що це (трекінг?).
- **Ціни.** Публічного прайсу немає — на сайті жодних цифр; калькулятор цін свідомо не робили.
- **Підтвердження SMS** — у старому відгуку на Birdeye згадано «confirmations come by text», але офіційно не підтверджено; на сайті цієї обіцянки немає.
- **Фото пацієнтів.** Не публікуємо жодних; «до/після» — ілюстрація з підписом.
- **Чи говорить персонал іспанською.** Сайт зроблено двома мовами, але це не підтверджено джерелом.

## Журнал змін — передача (21.11.2026)

Перевірено всі 36 сторінок (EN + ES) на десктопі й телефоні: без помилок JS, без горизонтального
скролу, без битих посилань і якорів. Що виправлено у версії MiniMax:

**Факти**
- Відгуки замінено на перевірені дослівні уривки з Google (Trustindex, 1 021 відгук); прибрано
  неіснуючі/переписані цитати (Dyetra Ashford, Paula Soileau, Timmy Kulik, «друге речення» Christian W.).
- Прибрано вигадані обіцянки: безкоштовна парковка, автобуси, «офіс на північному боці», «Same-week slots».
- Зі сторінки відгуків прибрано внутрішню нотатку «worth mentioning in a letter».
- Райони: англійські підписи замість іспанських на EN-сторінках, виправлено напрямок для Cypress.
- `sitemap.xml`: без дублів, справжній домен; canonical, hreflang і `og:image` тепер абсолютні
  (прев'ю посилання в месенджерах працює). Прибрано вигаданий домен `tdpstudio.com`.

**Іспанська**
- Перекладено все, що лишалось англійською: питання FAQ на всіх сторінках послуг, юридичні сторінки,
  дні тижня в годинах, футер, aria-підписи, ступені лікарів.
- Виправлено помилки: «¿Do you see children?», «Avise-nos», «highlightarlo», «dizer», «implantal»,
  «Ejercida», «carrera-investigó», «Horario con evenings»; «práctica» → «clínica», «colonias» → «vecindarios».

**Форма й інтерактив**
- Форма завжди надсилає канонічні англійські значення (раніше іспанське «Odontología estética»
  не проходило перевірку API і падало в «Something else»).
- Кнопки «Ask about an implant» / «Book my cleaning» тепер передають вибір на сторінку запису (`?reason=`).
- «Час дня» за замовчуванням — «Either»; у тесті найвищий результат веде на дзвінок, а не на форму.
- Чип пільг: «2026 dental benefits · 41 days left» замість незрозумілого «2026 · 41 days left».

**Дизайн**
- Повернуто креслення зуба в героя (було обрізане правим краєм).
- Послуги: 3 + 2 картки без сироти; додано ілюстрації для імплантів, реставрації й невідкладної допомоги.
- Сторінки послуг: ілюстрація в героя, сітка 2×2, фото будівлі + «Як проходить візит», без подвійного CTA.
- Команда: групове фото (з підписом фотографа), сітка 3×2, картка Shari з монограмою.
- «Візит»: фото офісу в героя; виправлено гігантську іконку в кнопці «Get directions» і темний
  заголовок «Office hours» на темному фоні.
- Повернуто іконки «Electronic health records» і «Blankets and pillows».
