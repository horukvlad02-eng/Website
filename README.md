# EaDo Family Dental — концепт редизайну (EN + ES)

Приватний концепт сайту для **EaDo Family Dental** (Х'юстон, Техас): дві клініки (EaDo і Northside),
двоє лікарів, 18 сторінок × 2 мови. Генератор статики на Python, одна Vercel-функція для заявок.

> **Це не офіційний сайт клініки.** `noindex`, плашка про концепт на кожній сторінці, заявки йдуть розробнику.
> Демо: https://eado-family-dental.vercel.app · код: гілка `eado-family-dental` у `horukvlad02-eng/Website`.

## Що всередині
- Дві клініки всюди: живий статус «відчинено/зачинено» для кожної (час Х'юстона), картки з годинами, схема міста, вибір клініки у формі запису (поле `location` у заявці).
- Світла тема за замовчуванням + темна (перемикач у шапці й у мобільному меню), 3D-картки, EN/ES.
- Відгуки — дослівні фрагменти з сайту клініки та Yelp (`research/eado/facts.md`), без вигаданих дат.
- Фото лікарів, команди й офісу — від клініки (див. `CREDITS.md`). Портрет можна замінити у `build/data.py` (DOCTORS → `photo`).

## Збірка
```
python3 build/build.py
```
Редагувати лише `build/*.py` (факти — `data.py`, тексти — `copy_en.py`/`copy_es.py`), стилі бренду — кінець `assets/classic.css`.
Темна тема генерується автоматично (`build/gen_dark.py` + `build/partials/dark-manual.css`).

## Заявки
Ті самі змінні оточення, що й в Acadian: `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` (або `RESEND_API_KEY` + `LEAD_TO_EMAIL`, або `LEAD_WEBHOOK_URL`) → Redeploy.
